# Global-Electronics-Retail-Analysis

## Project Overview
This project analyzes global electronics retail sales data using MySQL and Power BI. The dashboard provides insights into sales performance, customer behavior, product trends, and regional store analysis.

## Tools & Technologies
- MySQL
- Power BI
- DAX
- SQL
- Data Modeling

## Key Features
- Interactive Power BI dashboards
- Customer insights analysis
- Product performance tracking
- Store and regional analysis
- KPI monitoring
- Top-selling product analysis
- Sales trend analysis

## Dashboard Pages
1. Global Electronics Retail Analysis Dashboard
2. Customer Insights Dashboard
3. Product Performance Dashboard
4. Store & Regional Performance Dashboard
